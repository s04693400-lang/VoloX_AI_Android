
# VoloX AI

VoloX AI is an Android search and AI assistant project.

## Features

- Web search
- AI chat interface
- Image search
- AI image creation interface
- Visual search interface
- News
- Sports
- Discover
- User profile
- Settings

## Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express
- OpenAI API
- Capacitor

## Backend

The backend requires a private OpenAI API key configured as an environment variable.

Never commit API keys or `.env` files to GitHub.

## Android

Capacitor is used to prepare the Android application.

The Android project must be generated and built using a compatible development environment.
